Current Release: Version 6.5 (July 2026)

Download : mark59-6.6.zip
(640.3 MB download via Google Drive link)

Summary
- Java 17+ is now required for all Mark59 components
- UI Scripting : Multiple arguments within BROWSER_LAUNCH_ARGS can now be separated by a semi-colon (;) or ",--" characters.
- UI Scripting and Metrics-API : Version numbers are printed for both the mark59-metrics-api and the first Mark59UI script loaded.
- UI Scripting : Additional (User defined) Parameters now displayed at top of parameter list on the JMeter Java Request Panel.
- Trends Graph : Now displays a controlled error message when disallowed SQL is attempted, rather that the default error page.
- Dependencies Updated: spring-boot to 4.0.7, selenium to 4.45.0 (chrome v149), playwright to 1.61.0
- SimpleAES has been removed. SecureAES should be now used for encryption.

Full release details at at: https://github.com/mark-5-9/mark59?tab=readme-ov-file#releases
